# Fresh-family validation

Authoritative configuration: `configs/fresh.json`. This package is separate from the frozen structural study. Its attempt is `../runs/20261121_fresh01`; report is `../reports/20261121_fresh01`.

The prospective design has64 new setting families and256 full60-epoch trajectories, split32/32families. Development source-normal support20/20models and8/8outcome families plus valid5/3fold CV is a hard gate before evaluation generation/training. Evaluation support, conditional specificity, practical gain, panels and influence have separate frozen flags. Failure does not trigger automatic redesign or a manuscript update.

Use `instructions/STEP_BY_STEP.txt`. `run.ps1 all` executes all permissible stages and stops dependent work when the gate fails. Numeric package versions are preserved in `../../Feasibility/.venv`. No pretrained model, architecture substitution, Waterbirds or global install is needed.

The helper adaptations preserve the verified original generator/telemetry and structural-statistic definitions, but do not import old command modules. Original scientific artifacts, papers and proposal are protected by hashes. Checkpoint/resume state includes optimiser, RNG, data, source and protocol identities.
