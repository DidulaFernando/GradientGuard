COMPILE THE PORTABLE SOURCE PACKAGE
Use XeLaTeX (run twice), or Tectonic:

  tectonic -X compile GradientGuard_IEEE_Access_v1_2.tex

In Overleaf, upload the package contents, select XeLaTeX and choose
GradientGuard_IEEE_Access_v1_2.tex as the main document. Ordinary LaTeX packages
must be available. Generated figure/evidence files are already supplied; no
classifier training or forecaster fitting is required to compile the paper.

The legacy IEEE Access class mirror is included without edits. spotcolor.sty is
an explicit XeTeX compatibility shim producing the declared process-CMYK colour.
The direct current official template download was blocked by its website challenge.
Compare/migrate to the then-current official template before journal submission.

REBUILD TABLES AND FIGURES FROM THE FULL RESEARCH WORKSPACE
build.ps1, prepare_evidence.py and validate_manuscript.py are provided for the
original full repository layout. They depend on the preserved Feasibility tree
and recorded V9 proposal source; these are not duplicated in this small package.
The primary research repository is:
https://github.com/DidulaFernando/GradientGuard

This is an exploratory manuscript, not a journal-accepted paper. It preserves
the original nine-audit tie, the positive post-hoc twelve-audit observations,
uncertainty, full-cohort comparisons and outstanding structural controls.
V9's prospective studies are not presented as completed results.

No journal submission or public upload is authorised by producing this draft.
